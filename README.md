# Bright Future Academy - Tuition Institute Management System

SE2030 group project (Spring Boot + React/Vite + MySQL).

## Run backend
cd bright-future-academy
copy .env.example to .env and fill DB password / JWT secret
mvn spring-boot:run

## Run frontend
cd frontend
copy .env.example to .env
npm install
npm run dev

## Team / modules
1. Authentication, Security & Dashboard
2. Student & Parent Management
3. Teacher, Academic & Feedback
4. Attendance (NFC), Announcements & Landing page
5. Fee & Payment
6. Exam Management
